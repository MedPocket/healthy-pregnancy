# Healthy Pregnancy

[**Your Guide To Healthy Pregnancy**](https://my.clevelandclinic.org/-/scassets/files/org/obgyn/healthy-pregnancy-guide-20.pdf) provides essential prenatal care information, safe medications, and delivery preparation by [Cleveland Clinic](https://my.clevelandclinic.org).

Translated into Vietnamese by Ha Nhan, this project utilizes the [**Blume**](https://useblume.dev) documentation framework, powered by Astro and Vite.

## Develop locally

To get started, make sure you have [Node.js](https://nodejs.org) and [Bun](https://bun.com) installed on your system. Then, follow these steps:

```bash
git clone https://github.com/MedPocket/healthy-pregnancy
cd healthy-pregnancy
bun install
bun dev
```

Open your web browser and navigate to http://localhost:4321/healthy-pregnancy.
